CLI Repository
The CLI tool offers a command-line interface for users to authenticate and manage their profiles directly from a terminal. It utilizes the PKCE flow to ensure that client secrets are never exposed on the user's machine, instead relying on a code verifier generated during the login process. Upon initiation, the CLI opens a browser window for the user to complete the GitHub authorization and then listens on a local port to receive the resulting access and refresh tokens. These tokens are used to authorize subsequent API requests, allowing the user to interact with the backend services securely. Like the other components, the CLI is designed to operate within the strict three-minute and five-minute token expiration windows to ensure session integrity.
